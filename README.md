# KU Bridge — React (v3 요구사항 대응 독립 재구현 v2)

> **중요:** 이 프로젝트는 이전 ChatGPT Sites에 배포했던 KU Bridge v3의 **원본 저장소를 추출한 것이 아닙니다.** 확인된 v3 기능 요구사항을 기준으로 별도 작성한 React 구현입니다. 이전 사이트의 픽셀 단위 디자인이나 원본 코드의 동일성은 검증할 수 없습니다. 기존 라이브 사이트는 변경되지 않았습니다.

건국대학교 **서울캠퍼스** 외국인 유학생들이 학교 제도와 행정 절차를 쉽게 발견하고 학교 공식 안내까지 이동할 수 있도록 만든 독립형 탐색 서비스입니다. 건국대학교가 운영하는 공식 사이트가 아닙니다.

## 실행하기

요구 환경: Node.js 20 이상, 인터넷 연결(npm 패키지 최초 설치 시 필요)

```bash
npm install
npm run dev
```

브라우저에서 Vite가 출력한 로컬 URL(보통 `http://localhost:5173`)을 열어 사용합니다.

프로덕션 정적 빌드:

```bash
npm run build
npm run preview
```

배포는 생성된 `dist/` 디렉터리를 정적 웹 호스팅 서비스에 올리면 됩니다. Node.js 기반 서버나 데이터베이스는 필수가 아닙니다.

실행 전 콘텐츠 구조 테스트(외부 라이브러리 설치 없이 실행 가능):

```bash
npm test
```

## 최종 Sites v3 요구사항 대응

| v3 요구사항 | 별도 React 재구현 |
|---|---|
| 영어, 중국어 간체, 일본어, 한국어 | 4개 언어 지원: 메뉴, 상황 카드, 45개 주제의 제목/개별 설명/다음 단계, 문의 경로와 문안, 체크리스트 |
| PC/태블릿/모바일 | CSS 반응형 브레이크포인트, 작은 화면 언어 선택, 모바일 메뉴, 터치 대상 보강 |
| 지원제도 탐색 | 45개 유학생 관련 **탐색 주제**와 공식 출처 연결 |
| 검색 | 4개 언어 제목, 개별 설명과 다음 행동 문구까지 검색 가능 |
| 학생 유형 구분 | 학부, 대학원, 교환·방문, 어학과정 |
| 영역별 필터 | 학업, 학사·행정, 장학·등록금, 생활, 교류, 진로 |
| 상황별 안내 | 강의 이해, 교류, 부서 문의, 졸업 불안, 장학/생활 지원 등 5개 상황 |
| 담당 부서 경로 | 7개 문의 주제 × 4개 학생 유형; 우선 문의처, 다음 확인처 및 공식 근거 |
| 문의 문안 | 선택한 학생 유형·문의 주제가 반영된 4개 언어 복사 기능 |
| 졸업 체크리스트 | 학부 7개, 대학원 5개, 교환·방문 3개, 어학과정 2개 |
| 개인 저장 | 북마크, 언어 선택, 체크 상태는 브라우저 `localStorage`에 저장 |
| 정보의 신뢰성 | 확인된 공식 관련 내용, 일반 공식 탐색 경로, 과거 모집 사례를 구분 |

### 45개 항목의 성격

모든 항목이 현재 신청 가능한 **혜택 45건**을 뜻하지 않습니다. 입학 전부터 졸업까지 관련 제도, 학교 행정 절차, 교류 프로그램, 공식 안내 경로를 통틀어 **45개 탐색 주제**로 구성했습니다. 일부 자료는 과거 학기 모집 공지입니다.

금액, 지급요건, 신청 기간, 학번별 졸업요건과 담당 부서의 최종 책임은 반드시 학교 공식 페이지에서 확인하세요. 4개 언어 안내문은 **독립 프로젝트의 참고 번역**이며 건국대학교의 공식 번역이나 법적 판단이 아닙니다.

## 관리 및 운영 유의사항

- 운영 환경에서 실시간 공지 자동 수집, 사용자 로그인, 신청 대행, 민원 접수, 행정 부서 이관은 지원하지 않습니다.
- 체크리스트는 개인 기록 기능이며 대학의 졸업사정 결과와 무관합니다.
- React 프로젝트를 수정하여 재배포하더라도 이전 Sites v3 사이트가 자동으로 업데이트되지는 않습니다.
- 학교 정책과 지원사업은 변동될 수 있으므로 공식 출처와 각 학기 공지를 주기적으로 재검증해야 합니다.
- 유학생 대상 인터뷰는 1건이며 전체 유학생에 대한 일반화 근거로 사용하지 않습니다.
